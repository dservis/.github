# DataServis Sistemas

Desenvolvemos **sistemas de gestão empresarial (ERP), automação comercial e
soluções sob medida** para o comércio brasileiro desde 2005.

Somos de **Barbacena, Minas Gerais**, e atendemos empresas de mais de 30 cidades.

## Para quem trabalhamos

Varejo · Atacado · Bares · Restaurantes · Indústrias

## O que fazemos

- **Gestão empresarial (ERP):** financeiro, estoque, vendas e emissão de notas
  fiscais em um sistema integrado
- **Documentos fiscais eletrônicos:** NF-e, NFC-e e SPED
- **Automação comercial:** frente de caixa e terminais de autoatendimento
- **Mobile:** aplicativos que levam a gestão para fora do escritório
- **Soluções sob medida:** sistemas desenvolvidos para a necessidade de cada cliente
